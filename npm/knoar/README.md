# knoar

Reserved npm command package for [KnoArbor](https://github.com/pxcg/knoarbor).

KnoArbor is an AI-native Wiki engine that compiles multi-source information into a traceable, maintainable knowledge network.

The main KnoArbor runtime is currently distributed as a Python project. Use the repository quickstart for installation:

```bash
git clone https://github.com/pxcg/knoarbor.git
cd knoarbor
uv sync
uv run knoar serve
```

This npm package reserves the `knoar` command name for future JavaScript/Node-based launchers and integrations.
