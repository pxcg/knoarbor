# KnoArbor v1.3.0

KnoArbor v1.3.0 聚焦 Wiki 优先的对话体验、页面级检索、多知识库工作区和模型配置体验。

## 主要变化

- **Wiki 优先对话流程**
  - 新增有界对话循环，可以规划 Wiki 查询、复用上一轮证据、读取维护后的 Wiki 页面，并合成有依据的回答。
  - 对话助手保持在 KnoArbor 知识工作场景内，不扩展为通用 Agent 平台。

- **页面优先检索契约**
  - 明确 primary pages、supporting pages 和 source digest pages 的角色。
  - source digest 默认作为溯源材料；只有用户询问来源、出处或原始材料时才作为主要阅读对象。

- **多知识库工作区**
  - 运行时和前端支持知识库工作区选择。
  - 支持虚拟的全部知识库视图用于发现，同时写入流程仍限定在选中的知识库内。

- **模型配置改进**
  - 增加模型发现和面向本地模型的配置优化。
  - 改进 OpenAI-compatible、Ollama、vLLM、DeepSeek 和自定义端点的设置流程。

- **控制台更新**
  - 优化对话工作区、知识库选择和查询相关导航。
  - 更新当前本地控制台的打包资源。

## 文档

- 补充计划式 Wiki 工具架构说明。
- 补充页面优先检索契约说明。
- 明确后续开发继续在 `dev`，`main` 对齐本 release tag。

- 使用本地模型端点的用户建议检查模型供应商配置。
- 运行时知识库数据仍然保存在本地，并默认被 git 忽略。
- 后续开发继续在 `dev` 分支进行。
