# KnoArbor v1.3.0

KnoArbor v1.3.0 focuses on wiki-first chat, page-first retrieval, multi-vault
workspace behavior, and model configuration improvements.

## Highlights

- **Wiki-first chat workflow**
  - Adds a bounded chat loop that can plan wiki queries, reuse prior evidence,
    read maintained wiki pages, and synthesize grounded answers.
  - Keeps the chat assistant focused on KnoArbor knowledge work rather than a
    general-purpose agent surface.

- **Page-first retrieval contract**
  - Refines query behavior around primary pages, supporting pages, and source
    digest pages.
  - Treats source digest pages as provenance by default, while still allowing
    source-focused questions to inspect them directly.
  - Moves knowledge-page identity toward `pages/<slug>.md` with `page_kind`,
    `role`, `facets`, and `legacy_paths`; legacy typed paths remain readable
    during migration.

- **Multi-vault workspace support**
  - Extends runtime and UI surfaces with vault workspace selection.
  - Adds a virtual all-vault view for discovery while keeping write workflows
    scoped to a selected vault.

- **Model configuration improvements**
  - Adds provider model discovery and local-model-oriented configuration
    refinements.
  - Improves the model settings flow for OpenAI-compatible providers, Ollama,
    vLLM, DeepSeek, and custom endpoints.

- **Console updates**
  - Refines the chat workspace, vault selection flow, and query-oriented
    navigation.
  - Updates bundled UI assets for the current local console.

## Documentation

- Documents the planned wiki tool architecture.
- Documents the page-first retrieval contract.
- Keeps ongoing development on `dev`; `main` is aligned to this release tag.

## Upgrade Notes

- Review provider configuration if you use local model endpoints.
- Runtime vault data remains local and ignored by git.
- Ongoing development continues on the `dev` branch.
