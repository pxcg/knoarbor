# KnoArbor v2.2.1

KnoArbor v2.2.1 is a desktop patch release for chat evidence fidelity, image generation defaults, session list refresh behavior, and Windows desktop packaging.

## Highlights

- Chat evidence now preserves vault paths through retrieval and planning, allowing wiki attachment images to render from the correct local vault.
- Chat image generation now relies on configured provider defaults for runtime parameters such as aspect ratio, resolution, inference steps, and guidance.
- The chat session sidebar refreshes after successful chat updates, so new sessions appear without restarting the app.
- Desktop packaging now supports Windows NSIS builds alongside macOS DMG and ZIP artifacts.
- GitHub tag releases now build desktop artifacts on native macOS and Windows runners and attach them to the release.

## Upgrade Notes

- Desktop users can replace the existing app with the v2.2.1 build; local vaults and chat sessions remain under the app data directory.
- Windows users should migrate the full vault directory, not only chat session JSON files, when moving a desktop knowledge base from another machine.
- Existing image-generation provider settings continue to control default output parameters.

## Validation

- `uv run python -m unittest tests.test_wiki_attachments tests.test_chat_citations tests.test_runtime_contracts tests.test_chat_agent tests.test_image_generation tests.test_ui_api`
- `npm --prefix web run build`
- `npm --prefix desktop run pack:mac`
- Manual six-turn AC1 desktop chat covering context retrieval, attachment lookup, attachment rendering, image generation, and persisted session history.
