# KnoArbor v1.2.1

KnoArbor v1.2.1 improves local model provider configuration and diagnostics.
It is a patch release for users running KnoArbor with vLLM, Ollama, or other
OpenAI-compatible model endpoints.

## Highlights

- Provider-level `context_window` and `max_output_tokens` settings.
- vLLM context-window detection from `/v1/models` model metadata.
- Ollama context-window detection from `/api/show`.
- Automatic fallback to configured `context_window` when runtime detection is unavailable.
- Settings UI support for provider context and output-token limits.
- Doctor diagnostics now report detected and effective model context information.

## Notes

`max_tokens` passed by CLI or API still has the highest priority for a single
run. If it is omitted, KnoArbor uses the selected provider's
`max_output_tokens`; if that is omitted, it falls back to
`models.default_max_tokens`.

For local 32K-context models, a conservative starting point is:

```yaml
context_window: 32768
max_output_tokens: 8000
```
