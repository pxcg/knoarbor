# KnoArbor v2.0.0

KnoArbor v2.0.0 is the first release that centers the project around the desktop app and the upgraded ingest pipeline. It keeps the Python/FastAPI core in place, but packages a more complete desktop shell and expands document preprocessing so richer sources can enter ingest cleanly.

## Highlights

- Electron desktop app with managed service startup, restart, logs, diagnostics, and native menu actions.
- Desktop-oriented console updates for chat, configuration, run monitoring, wiki browsing, and reports.
- MinerU-backed document preprocessing for non-Markdown ingest sources.
- Ingest pipeline upgrades across source unitization, source digests, write gating, and report generation.
- Version metadata synchronized across the Python package and bundled web and desktop surfaces.

## Upgrade Notes

- Desktop users should treat this as the first packaged desktop release line rather than a thin web wrapper.
- Rich document ingest still depends on an external MinerU-compatible service; the desktop package does not bundle heavy OCR or model runtimes.
- Existing vault data remains local and file-based.
