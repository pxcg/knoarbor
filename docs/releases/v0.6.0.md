# KnoArbor v0.6.0

KnoArbor v0.6.0 is a release-readiness and console-polish release. It strengthens the public project presentation, broadens local source coverage, and makes the bundled management UI more useful for real daily operation.

## Highlights

- **Bundled management console refresh**
  - Refined the first-run console layout, run monitor, source settings, report viewer, graph view, and query controls.
  - Added project branding assets, neutral source icons, and generated screenshots for the README and showcase pages.
  - The root service now opens the management console directly, while API docs remain available separately.

- **Broader source coverage**
  - Added a generic chat connector for JSONL-style chat records.
  - Improved configured chat-source handling across Codex, Hermes, OpenClaw, Claude Code, and custom chat paths.
  - Source segmentation and run reporting now expose clearer progress for long documents and conversation logs.

- **Documentation for public users**
  - Added a Chinese README alongside the English README.
  - Added showcase pages and screenshot-led product tours.
  - Updated docs navigation and public product-tour material.

- **Release packaging hardening**
  - Kept the bundled UI self-contained while avoiding redistribution of third-party brand images.
  - Updated release checks, local gates, and E2E smoke coverage for the refreshed console.

## Validation

The release candidate passed:

- `scripts/dev-check.sh`
- `scripts/live-release-candidate-smoke.sh`
- Markdown local link and image validation across the docs tree

The live smoke path used a real DeepSeek-compatible provider and covered Markdown ingest, Codex chat ingest, structural lint, query retrieval, and temporary-vault cleanup.

## Upgrade Notes

- Package metadata is now synchronized at `0.6.0`.
- No config migration is required.
- Public v0.x workflow API paths remain stable.
- `/ui/api/*` remains reserved for the bundled management console and is not a stable external integration API.
