# KnoArbor v0.4.0

KnoArbor v0.4.0 is a multi-source ingest stability release. It keeps the v0.3 reliability foundation and focuses on making real local chat sources, source preflight, and long-running CLI workflows more predictable before the first public launch.

## Highlights

- **More robust local chat source ingest**
  - Codex, Claude Code, and OpenClaw connectors now share a tolerant JSONL reader.
  - A single malformed or incomplete JSONL line is skipped with warnings instead of failing the whole connector run.
  - Representative real local session directories were validated through compact preflight.

- **Safer source preflight**
  - `knoar sources --json` now returns compact metadata by default.
  - Full normalized source content is still available with `--include-content` when a caller explicitly needs it.
  - This keeps preflight usable for long chat sessions without flooding terminals or automation logs.

- **Progress-first long CLI runs**
  - Human-readable `ingest`, `ingest-file`, and `lint-run` now follow local run progress by default.
  - Event and heartbeat output make long model-backed workflows easier to trust.
  - `--json` remains clean machine-readable output, and `--no-follow` keeps synchronous summaries available for debugging.

- **Single-file ingest progress**
  - `ingest-file` now uses the same local queue-follow path as connector ingest when used interactively.
  - Markdown files and MinerU-preprocessed rich documents can surface progress consistently.

- **v0.4 ingest acceptance matrix**
  - The internal capability map now records the expected preflight and write-capable validation surface for Markdown, Hermes, Codex, Claude Code, OpenClaw, and MinerU-preprocessed documents.

## Validation

The release candidate should pass:

- `scripts/dev-check.sh`
- `scripts/release-readiness.py`
- `scripts/clean-clone-smoke.sh`
- `scripts/release-check.sh`

Additional live-model validation performed for v0.4 development:

- Real-source compact preflight for Codex, Claude Code, and OpenClaw local session directories.
- Temporary-vault write-capable ingest for Codex, Claude Code, and OpenClaw.
- Follow-up lint and query smoke on the generated temporary vault.

## Known Boundaries

- KnoArbor remains an alpha, local-first, single-user project.
- Query returns structured local context for a host AI; it does not generate the final chat answer.
- Same-vault write-capable workflows are serialized by the local queue.
- Built-in vector search, hosted SaaS deployment, user authentication, and bundled MinerU runtime remain out of scope.
- Tolerant JSONL parsing skips malformed lines but does not attempt to repair provider-specific corrupted session files.

## Upgrade Notes

- Public high-level workflow API paths remain stable: `/ingest/*`, `/lint/*`, `/query/*`, and `/runs/*`.
- CLI users who relied on synchronous human-readable `ingest` or `lint-run` summaries can pass `--no-follow`.
- Automation should continue using `--json`; it remains free of progress-event output.
