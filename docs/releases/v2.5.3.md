# KnoArbor v2.5.3

KnoArbor 2.5.3 brings the public repository to the current local-first factual
architecture while preserving its independent product identity and public
distribution boundary.

## Highlights

- Immutable factual source revisions and explicit active source heads replace
  mutable generated-page authority.
- Transactional ingest publishes Raw evidence, semantic metadata, readable
  projections, and rebuildable indexes through one coordinated lifecycle.
- Query and Chat use unified active-Raw retrieval with typed outcomes, stable
  evidence handles, citation resolution, and separate answer-decision and
  response-composition stages.
- The renderer and desktop shell now expose current settings, run monitoring,
  Raw/projection editing, knowledge navigation, and safe local IPC contracts.
- Public packaging retains KnoArbor branding, `ai.knoarbor.desktop`, local
  application data, and no enterprise update channel.

## Compatibility

Legacy mutable wiki-writer, page-first retrieval, and graph-led chat paths are
retired. Existing vaults are reconciled through the factual-revision migration
and materialization boundaries documented in
[Backup and Recovery](../BACKUP_AND_RECOVERY.md) and
[API Compatibility](../API_COMPATIBILITY.md).
