# KnoArbor v1.0.0

KnoArbor v1.0.0 is the first public local-first release. It packages the core knowledge workflow, stable API surface, local management console, CLI, and host-AI skill template into one repository.

## Highlights

- **Ingest**: compile Markdown notes, AI chat sessions, generic chat logs, prepared source documents, and optionally preprocessed rich documents into a maintained Markdown wiki.
- **Lint**: run deterministic and semantic maintenance over wiki structure, links, provenance, and page quality, with reviewed repairs and human-readable reports.
- **Query**: retrieve ranked wiki pages, excerpts, source pointers, related context, and context packs for host AI tools.
- **Console**: configure sources and models, inspect workflow runs, read reports, browse wiki pages, view graph links, and analyze token usage from the bundled local UI.
- **Skill integration**: use the packaged local skill template to query KnoArbor from compatible AI tools.
- **npm namespace**: reserve the `knoarbor` package and shorter `knoar` command package for future JavaScript/Node launchers and integrations.

## Stable Public Interfaces

The 1.0 public API surface is intentionally small:

- `GET /health`
- `GET /doctor`
- `POST /ingest`
- `POST /lint`
- `POST /query`
- `POST /query/feedback`
- `GET /query/trends`
- `GET /runs`
- `GET /runs/{run_id}`
- `GET /runs/{run_id}/events`
- `GET /runs/{run_id}/stream`
- `POST /runs/{run_id}/cancel`
- `GET /wiki/pages`
- `GET /wiki/pages/content`
- `GET /wiki/pages/links`

The bundled console also uses `/ui/*` routes, but those are reserved for the web UI and may evolve with the console implementation.

## Release Boundaries

- KnoArbor is local-first and single-user.
- The runtime `wiki/` vault, `.env`, `config.yaml`, caches, and local workflow exports are intentionally ignored by git.
- KnoArbor does not bundle model weights, a hosted SaaS backend, a vector database, a chat answer generator, or a MinerU runtime.
- Optional document preprocessing requires a separately installed MinerU-compatible service.

## Upgrade Notes

If you used a pre-1.0 build:

- Replace old `ingest-file` usage with `knoar ingest --input ...`.
- Replace old `lint-run` usage with `knoar lint --mode ...`.
- Treat `/ingest`, `/lint`, `/query`, `/runs`, and `/wiki/pages/*` as the long-term API surface.

## Validation

The release candidate should pass:

```bash
scripts/dev-check.sh
scripts/release-readiness.py
scripts/clean-clone-smoke.sh
```

When a real model provider is available, also run:

```bash
set -a && source .env && set +a
scripts/live-release-candidate-smoke.sh
```
