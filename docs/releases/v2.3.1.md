# KnoArbor v2.3.1

KnoArbor v2.3.1 is a desktop packaging and configuration reliability release.

## Highlights

- The desktop UI source now lives in the renderer workspace.
- Packaged desktop builds load renderer assets from Electron resources instead of serving the UI through the local HTTP service.
- Desktop configuration saves use Electron IPC, reducing the chance that enterprise DLP tools classify local settings writes as browser uploads.
- The old bundled UI dist has been removed from the Python package tree.

## Validation

- `npm --prefix renderer run build`
- `npm --prefix desktop run build`
- `uv run python -m unittest tests.test_ui_api tests.test_desktop_config_cli tests.test_wiki_attachments`

## Upgrade Notes

- Desktop users can replace the existing app with the v2.3.1 build. Local vaults and configuration remain under the app data directory.
