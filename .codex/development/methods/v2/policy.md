# KnoArbor Development Method v2 Policy

## Authority

This immutable method version governs every Initiative whose manifest pins this
directory. Feature specifications own product tasks; the checkpoint owns current
development execution state.

## Invariants

- Run cognitive roles synchronously; do not create a persistent Agent team.
- Downstream roles never rewrite accepted upstream artifacts.
- Reviewers do not mutate repository files.
- Run only catalogued gates without a shell and discard raw output.
- Require explicit human decisions at configured authority boundaries.
- Require explicit side-effect authorization and idempotent delivery identity.
- Stop at budget exhaustion, three consecutive rejections, corrupt state, method
  drift, scope overflow, hard-gate delta, or incomplete soft scars.
- Persist no credential, prompt, source body, raw command output, environment
  value, or absolute private path in portable evidence.

## Completion

Only the Controller may resolve closure. Closure requires accepted product
evidence, delivered or side-effect-free local delivery state, a sealed acceptance
snapshot, regenerated handoff and metrics, and no unresolved blocker.
